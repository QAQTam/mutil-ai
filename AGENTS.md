# Git attribution

For commits containing work assisted by OpenAI Codex in this repository, append
the following commit-message trailer, separated from the body by a blank line:

```text
Co-authored-by: Codex <noreply@openai.com>
```

Keep the human contributor as the primary Git author and preserve any existing
co-author trailers. Do not add Codex attribution to unrelated human-only commits.
Do not rewrite pushed commits or move published release tags solely to add attribution.
